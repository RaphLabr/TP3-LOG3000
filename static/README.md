# Readme: module "static"

## Objectif du module
Le module "static" rassemble le code CSS de l'application qui dicte les règles d'affichage des éléments html de l'application

## Fichiers du module
Le module "static" rassemble les fichiers suivants:
style.css

## Responsabilité des fichiers
Le fichier style.css est responsable des règles d'affichage du fichier index.html du module
