# TP3-LOG3000
Équipe #45

Objectif:
Le but de ce projet est d'implémenter une calculatrice web basique en Python. Elle est capable de supporter l'addition, la soustraction, la multiplication et la division

Prérequis:
Avoir python 3.13.5 installé sur son ordinateur
Avoir pip 26.2.1 installé sur son ordinateur
Rouler la commande pip install -r requirements.txt

Comment partir le projet:
Rouler la commande python app.py
Pour accéder au Front-End il suffit d'ouvrir un navigateur web et se connecter au port indiqué dans le terminal (qui devrait être http://127.0.0.1:5000)
